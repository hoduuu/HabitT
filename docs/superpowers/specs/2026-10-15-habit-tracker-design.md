# 해빗 트래커 (Android) 설계

- 작성일: 2026-10-15
- 상태: 설계 승인됨, 구현 계획 전
- 시안: `.superpowers/brainstorm/647-1791989205/content/` (`diary-layout-v2.html`, `styles-dark.html`의 라이트 열)

## 1. 목적

지금 쓰는 해빗 트래커 앱은 위젯이 없고 디자인이 마음에 들지 않는다. 같은 핵심 기능(습관별 월 격자에 완료/미완료 체크)을 **다이어리 느낌의 예쁜 디자인**과 **홈 화면 위젯**으로 다시 만든다. 개인용, 폰 한 대에서만 쓴다.

## 2. 범위

### 포함
- 습관별 이번 달 격자 (완료/미완료 이진 체크)
- 월 이동 (`‹ 26년 10월 ›`)
- 오늘·지난 날짜 체크 수정 (앱 안에서만)
- 습관 추가/수정/삭제/순서 변경, 습관별 이모지 1개 + 파스텔 색 1개
- 카드 스타일 2종(C 인덱스 탭 / A 마스킹테이프), 설정에서 전역 선택
- 홈 화면 위젯: 위젯 1개 = 습관 1개, 보기 전용, 크기 조절 가능

### 제외 (YAGNI)
- 다크 모드 (추후 추가 예정 — 스타일 토큰을 라이트/다크로 나눌 수 있게만 구성)
- 년도 보기, 하단 탭
- 연속 기록·"다시 시작"·달성률 같은 동기부여 요소, "N일 완료" 표시
- 알림, 백업/동기화/내보내기
- 횟수·시간 기반 습관
- 위젯에서 직접 체크

## 3. 앱 화면

### 3.1 메인 화면 (유일한 주 화면)
- 상단: `‹  26년 10월  ›` — 이전/다음 달 이동. 오른쪽 위에 `＋`(습관 추가), `⚙️`(설정).
- 본문: 습관 카드를 사용자 지정 순서대로 세로 나열 (스크롤).
- 습관이 없으면 빈 상태 안내("＋를 눌러 첫 습관을 만들어요").
- 앱 시작 시 이번 달을 보여준다.

### 3.2 격자
- 달력 배치: 7열, **일요일 시작**, 첫 행 위에 손글씨 요일 머리글 `일 월 화 수 목 금 토`.
- 1일 앞의 빈 칸 수 = 1일의 요일 인덱스(일=0). 행 수는 4~6.
- 칸은 **동그라미**.
  - 완료: 습관 색으로 채움
  - 미완료(오늘 이전·오늘): 연한 베이지 `#f3ebe3`
  - 미래: 더 연한 `#faf5ef`
  - 오늘: 습관 색 2px 테두리 링
- 칸 탭 → 완료/미완료 토글. 미래 칸은 탭 무반응. 지난 달로 이동해도 동일하게 수정 가능.

### 3.3 습관 편집 (바텀시트)
- 진입: `＋` (새 습관) 또는 카드 길게 누르기 (수정).
- 필드: 이름(필수, 공백 불가), 이모지 1개(시스템 이모지 키보드 입력, 첫 이모지 1개만 저장, 기본값 📝), 색(파스텔 8색 중 1개).
- 수정 모드에만 `삭제` 버튼 → 확인 다이얼로그 → 습관과 모든 체크 기록 삭제.

### 3.4 순서 변경
- 카드를 길게 누른 채 드래그해서 이동. (길게 누르고 움직이지 않고 떼면 편집 시트 열림)

### 3.5 설정
- 카드 스타일: `C 인덱스 탭`(기본) / `A 마스킹테이프`. 앱 전체와 모든 위젯에 적용.

## 4. 시각 디자인 (라이트)

### 4.1 공통 토큰
| 토큰 | 값 |
|---|---|
| 페이지 배경 | `#fff8f0` |
| 종이(카드) | `#fffdf9` |
| 본문 글자 | `#5b4636` |
| 요일 머리글 | `#c4ab97` |
| 빈 칸 / 미래 칸 | `#f3ebe3` / `#faf5ef` |
| 모눈 점 (C) | `#ead9c9` |
| 습관 팔레트 (8) | `#ffb38a` `#ffd27a` `#9ccfa8` `#8fd3d0` `#a9c4f5` `#c7b2f0` `#f5a9c8` `#d9b99b` |

### 4.2 스타일 C — 인덱스 탭 + 도장 (기본)
- 카드 위 왼쪽에 습관 색 **인덱스 탭**, 탭 안에 습관 이름 (폰트 Gamja Flower, 흰 글씨).
- 본문: 점 모눈종이 배경, 습관 색 2px 테두리, 모서리 `4 18 18 18`.
- 왼쪽에 이모지를 **점선 동그라미 도장**(습관 색 dashed, -10° 회전) 안에 배치, 오른쪽에 격자.
- 요일 머리글 폰트 Gamja Flower.

### 4.3 스타일 A — 마스킹테이프 + 스티커
- 종이 카드, 은은한 그림자, 카드마다 ±1° 번갈아 기울임.
- 카드 상단 가운데에 반투명 **마스킹테이프** 조각 (테이프 색은 습관 색과 다른 팔레트 색을 습관 id 기준으로 결정적으로 고름).
- 첫 줄: 이모지(-8° 회전, 스티커 느낌) + 습관 이름 (폰트 Gaegu Bold).
- 아래 가운데 격자. 요일 머리글 폰트 Gaegu.

### 4.4 폰트
- Gaegu(Regular/Bold), Gamja Flower — OFL 라이선스, 앱에 번들(`res/font`).

## 5. 위젯

- **추가 시**: 습관 선택 화면(구성 Activity)에서 습관 1개 선택 → 위젯과 습관 id 연결 저장.
- **표시**: 앱 카드와 같은 모양(현재 스타일 C/A), 이번 달 격자 전체.
- **렌더링 방식**: RemoteViews는 커스텀 폰트를 쓸 수 없으므로, 카드를 `Canvas`로 **비트맵을 그려** `ImageView` 하나에 넣는다. 위젯 크기(`OPTION_APPWIDGET_*`)에 맞춰 비율을 유지하며 스케일.
- **최소 크기**: 격자 31칸이 읽히는 크기로 지정 (초기값 약 3×2 셀, 실기기에서 조정). 그 이상은 자유 리사이즈 (`resizeMode=horizontal|vertical`).
- **탭**: 위젯 어디를 탭해도 앱 메인 화면을 연다. 위젯에서 체크하지 않는다.
- **갱신 시점**: 앱에서 체크/습관 수정/삭제/스타일 변경 시, 자정(날짜 변경), 위젯 크기 변경 시, 시간대·날짜 변경 브로드캐스트 시.
- **연결된 습관이 삭제된 경우**: "습관이 삭제됐어요 · 탭해서 다시 고르기" 표시, 탭하면 습관 선택 화면.

## 6. 아키텍처

- 언어/UI: Kotlin, Jetpack Compose (Material 3 최소 사용, 대부분 커스텀 드로잉)
- 최소 SDK 26 (Android 8.0), target 최신 안정 버전
- 단일 모듈 앱, 패키지 구성:

| 패키지 | 책임 | 의존 |
|---|---|---|
| `data` | Room: `Habit(id, name, emoji, colorIndex, sortOrder)`, `Check(habitId, date: LocalDate)` (PK = habitId+date, Habit 삭제 시 CASCADE). DataStore: 카드 스타일. `HabitRepository`가 Flow로 노출 | — |
| `calendar` | `MonthGrid` 계산: 연·월·오늘 → 앞 빈칸 수, 일수, 각 칸 상태(완료/과거/오늘/미래). 순수 Kotlin | — |
| `style` | 스타일 C/A의 색·크기·폰트·장식 파라미터 정의 (앱과 위젯 공용) | — |
| `ui` | 메인 화면, 카드 컴포저블(C/A), 편집 바텀시트, 설정 화면, `MainViewModel` | data, calendar, style |
| `widget` | `HabitWidgetProvider`, 구성 Activity, `CardBitmapRenderer`(Canvas로 C/A 그리기), 자정 갱신 스케줄, 위젯↔습관 매핑 저장 | data, calendar, style |

- 앱 카드는 Compose로, 위젯 카드는 Canvas로 각각 그리되 **같은 `style` 값과 같은 `MonthGrid`** 를 사용해 모양을 맞춘다.
- 데이터·스타일 변경 → `WidgetUpdater`가 해당 위젯들의 비트맵을 다시 그려 `AppWidgetManager.updateAppWidget`으로 반영한다.

## 7. 오류·예외 처리
- 이름이 비어 있으면 저장 버튼 비활성.
- 이모지 입력이 비면 기본 📝.
- 월 경계·윤년은 `java.time`에 맡긴다.
- 위젯이 가리키는 습관이 없으면 5장의 안내 상태.

## 8. 테스트
- 단위 테스트: `MonthGrid` (2026-10 → 앞 빈칸 4·31일, 2027-02 → 28일, 윤년 2028-02 → 29일, 일요일 시작 달 → 빈칸 0, 오늘/미래 판정), 위젯 비트맵 크기·스케일 계산, Repository 토글 로직(Room in-memory).
- 수동 확인: 실기기 설치 후 체크·월 이동·편집·삭제·순서 변경·스타일 전환·위젯 추가/리사이즈/자정 넘김.

## 9. 빌드·배포
- 개발 환경: JDK 17 + Android 명령줄 도구(SDK) 설치 (Android Studio 없이 Gradle wrapper로 빌드).
- 산출물: 서명된 release APK. 키스토어는 프로젝트 밖에 보관하고 경로·비밀번호는 git에 넣지 않는다 (키 분실 시 업데이트 설치 불가).
- 설치: USB + adb, 또는 APK 파일을 폰으로 복사해 설치.
